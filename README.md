# CHEMIA

A premium, private, consent-first spicy couples game designed for Android browsers and installable as a PWA.

## Core
- Two-player local play
- Soft / Spicy / Hot / Extreme intensity
- Weighted card engine with anti-repeat protection
- Heat meter, chains, secret missions, afterglow and endless mode
- One-device pass-and-play privacy flow
- Offline-first localStorage persistence
- 500-card-ready content schema (starter deck included)
- No account required

## Content policy
CHEMIA uses romantic, flirtatious and suggestive content for consenting adults. It does not provide graphic sexual instructions.

## Run
Open `index.html` in a modern browser. For a full PWA install experience, serve the repository over HTTPS or localhost.

## Project structure
- `index.html` — app shell
- `styles.css` — premium mobile-first UI
- `app.js` — game engine, state, persistence and rendering
- `manifest.webmanifest` — PWA metadata
- `service-worker.js` — offline cache
- `data/cards.js` — starter deck and content schema
- `tests/test-engine.js` — lightweight engine checks
